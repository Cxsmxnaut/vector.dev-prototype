# vector.dev v0.2.0

First public development prerelease of vector.dev, a local desktop and browser workspace for Codex.

## Downloads and installation

- **DMG:** `vector.dev-0.2.0-macos-arm64.dmg` — open and drag vector.dev into Applications.
- **ZIP:** `vector.dev-0.2.0-macos-arm64.zip` — extract the application into Applications.
- **SHA256SUMS:** download alongside both assets and run `shasum -a 256 -c SHA256SUMS` to check integrity.

Requires an **Apple Silicon Mac, macOS 13 or newer, a compatible installed Codex executable, and an existing Codex sign-in**. Keep the Codex desktop host installed if you use its bundled executable. Tested with Codex `0.164.0-alpha.11.1`; backend compatibility can change across versions. Intel, Windows, and Linux binaries are not included.

The app is **ad-hoc signed for integrity, but is not Developer ID signed or Apple-notarized**. macOS may block it. Automatic updates are not included.

## Included

- vector.dev branding, icon, native Mac application, and browser interface.
- Existing local Codex chats and history, with the host's sidebar organization projected every five seconds.
- Streaming chats, approvals, model selection, stop/steer, attachments, rename, archive, restore, and fork.
- Persistent drafts and tabs, conflict detection between windows, and backend reconnection.
- Syntax editor, project search, save previews, backups and restoration, plus a host terminal.
- Git staging, reviewed commits, branches/worktrees, and controls for push and draft pull requests.
- Local skills/plugins, MCP status/OAuth, usage, basic settings, goals, and code review.
- Optional native task/approval notifications, disabled until enabled; private titles by default.

## Known limitations

This is not a complete replacement for the Codex desktop app. Exact two-way host sidebar editing, cloud/remote chats, Spaces/Sites and hosted app interfaces, voice, independent native browser/computer-control integration, mobile access, and independent automation scheduling are not implemented. The host's private sidebar state is read-only.

Git push/PR controls and native notification delivery need further live validation. The terminal runs with host permissions. Agent-powered operations consume the signed-in account's allowance or credits; no hosting subscription is added by vector.dev.

See [README](https://github.com/Cxsmxnaut/vector.dev/blob/v0.2.0/README.md) and [feature parity](https://github.com/Cxsmxnaut/vector.dev/blob/v0.2.0/PARITY.md) for requirements, permissions, and limitations. vector.dev is an independent client and is not affiliated with OpenAI.
